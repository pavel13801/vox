# Vox — ИИ-диктофон для iPhone (аналог Omi без лимитов)

Vox записывает разговоры с микрофона iPhone или с кулона **Omi** по Bluetooth, расшифровывает их через
**Deepgram** (или бесплатный Whisper от Groq), а потом с помощью любой языковой модели делает сводку,
вытаскивает задачи и факты о вас и даёт поговорить со своими записями в чате.

Сервера нет, подписки нет, лимитов минут нет: приложение ходит к провайдерам напрямую с **вашими ключами**,
а все данные лежат только на телефоне.

## 🌐 Веб-версия (без установки)

**https://pavel13801.github.io/vox/** — откройте в Safari на iPhone → «Поделиться» → «На экран «Домой»».

То же приложение в браузере: запись, live-расшифровка Deepgram, сводки, задачи, память, чат, импорт и экспорт.
Данные хранятся только в браузере на телефоне (IndexedDB), ключи отправляются напрямую провайдерам.

Ограничения iOS для веб-приложений:
- запись идёт, пока Vox **открыт на экране**: экран не гаснет во время записи, но если свернуть приложение,
  iOS остановит микрофон (при возврате запись продолжится новым разговором);
- кулон Omi через Web Bluetooth работает в браузере **Bluefy** на iPhone и в Chrome на Android/компьютере.
  Safari Bluetooth не поддерживает.

Ключи — от любых нейросетей: встроены Deepgram, Gemini, OpenAI, Groq, OpenRouter, Claude, DeepSeek, а через
«Настройки → Добавить любой другой ИИ» подключается любой сервис с OpenAI- или Anthropic-совместимым API
(Mistral, Grok, Qwen, Kimi, Together, Fireworks, Cerebras, Perplexity, Ollama…). Расшифровывать файлы умеют
Deepgram, Whisper-совместимые сервисы и модели с аудиовходом (Gemini).

Gemini, OpenAI и Claude не работают из России (ошибка 400 «location is not supported»): включите VPN, используйте
OpenRouter/DeepSeek или поднимите бесплатный прокси на Cloudflare — код в [`web/proxy-worker.js`](web/proxy-worker.js),
инструкция в приложении (Справка → прокси).

Для записи с заблокированным экраном и фонового подключения Omi нужна iOS-сборка (ниже).

Код веб-версии — в папке [`web/`](web/). Это чистый JavaScript без сборки; публикуется на GitHub Pages
workflow-ом [`.github/workflows/pages.yml`](.github/workflows/pages.yml).

## Возможности

| | |
|---|---|
| 🎙 Запись | Микрофон iPhone (в том числе с заблокированным экраном) или кулон Omi / Omi DevKit по BLE (Opus и PCM) |
| ⚡️ Live-расшифровка | Deepgram Nova-3 по WebSocket: текст появляется сразу, спикеры различаются, есть автопереподключение и буфер на время обрыва связи |
| 📄 Расшифровка файла | Deepgram (со спикерами), Groq Whisper (бесплатно) или OpenAI Whisper. Запускается автоматически, если пропадала связь |
| ✂️ Режим «весь день» | Сам делит поток на отдельные разговоры после N минут тишины (как Omi) |
| 🧠 ИИ-анализ | Название, эмодзи, категория, сводка, тезисы, задачи со сроками, имена спикеров. 8 шаблонов: протокол встречи, конспект лекции, звонок, интервью, идеи, дневник, чистовой текст диктовки |
| ✅ Задачи | Общий список задач из всех записей, сроки, отметки «выполнено» |
| 🧩 Память | Устойчивые факты о вас, которые ИИ собирает из записей |
| 💬 Чат | Вопросы по всем записям («о чём договорились на этой неделе?») или по одной записи |
| 🔌 Любая LLM | Google Gemini (бесплатный лимит), Groq (бесплатно), OpenAI, OpenRouter, Anthropic Claude, DeepSeek, свой OpenAI-совместимый сервер (Ollama, LM Studio) |
| 📥 Импорт | Аудио из «Файлов», Диктофона, Telegram и т. п. |
| 📤 Экспорт | Markdown (удобно для Obsidian), аудио, архив всех данных. Записи видны в «Файлах» → «На iPhone» → Vox |
| 🛟 Надёжность | Аудио сразу пишется на диск: если приложение упадёт, запись восстановится и обработается при следующем запуске |

## Что понадобится

1. **Ключ Deepgram**: [console.deepgram.com](https://console.deepgram.com). При регистрации дают $200,
   этого хватит примерно на 400 часов live-записи или 750 часов в режиме «После записи».
2. **Ключ ИИ**. Бесплатные варианты:
   [Google AI Studio](https://aistudio.google.com/apikey) (Gemini) или [Groq](https://console.groq.com/keys).
3. Компьютер с Windows и **iLoader** (или Sideloadly, AltStore) для установки.

## Сборка (GitHub Actions, Mac не нужен)

Каждый push в `main` собирает неподписанный `Vox.ipa` на бесплатной macOS-машине GitHub
(см. [`.github/workflows/build.yml`](.github/workflows/build.yml)) и публикует его в **Releases**.

Последняя сборка всегда доступна по ссылке:

```
https://github.com/<ваш-логин>/<репозиторий>/releases/latest/download/Vox.ipa
```

Локальная сборка на Mac: `brew install xcodegen && xcodegen generate && open Vox.xcodeproj`.

## Установка на iPhone

### Вариант 1: iLoader + SideStore (рекомендуется, бесплатно)

1. На ПК установите iTunes (нужен драйвер iPhone) и [iLoader](https://github.com/nab138/iloader)
   (`winget install --id nabdev.iloader --exact`).
2. На iPhone поставьте **LocalDevVPN** из App Store и включите
   «Настройки → Конфиденциальность → Режим разработчика».
3. Подключите iPhone кабелем, откройте iLoader, войдите своим Apple ID и выберите **Install SideStore**.
   iLoader сам положит файл сопряжения.
4. Скачайте `Vox.ipa` из Releases. В iLoader выберите **Install IPA** → `Vox.ipa`
   (или на телефоне: SideStore → My Apps → «+» → выбрать .ipa).
5. На iPhone: «Настройки → Основные → VPN и управление устройством» → доверьте свой Apple ID.

### Как сделать, чтобы приложение не «слетало»

Подпись бесплатного Apple ID действует 7 дней. Ваши данные при этом **не удаляются**, нужно лишь обновить подпись:

- **SideStore обновляет подпись прямо на телефоне**, без ПК: SideStore → My Apps → *Refresh All* (при включённом LocalDevVPN).
- **Полная автоматизация**: «Команды» → «Автоматизация» → «Время суток», каждый день → действие
  SideStore *Refresh All*. Подпись будет обновляться сама, и Vox не истечёт.
- Альтернатива: платный Apple Developer ($99/год), подпись на год.
- TrollStore (установка навсегда) работает только на iOS ≤ 17.0.

> Обновляйте Vox, ставя новую .ipa поверх старой: записи сохранятся.
> Не устанавливайте Vox внутрь LiveContainer: фоновая запись там может не работать.

## Первый запуск

1. **Настройки → Ключи API**: вставьте ключ Deepgram и ключ ИИ, нажмите «Сохранить и проверить».
2. **Настройки → ИИ-анализ**: выберите провайдера и модель (кнопка ⌄ загружает список доступных моделей).
3. Язык распознавания по умолчанию русский. Для смешанной речи (рус + англ) выберите «Мультиязычный».
4. Для Omi: «Настройки → Устройство Omi → Найти устройство». Если кулон подключён к официальному
   приложению Omi, сначала отвяжите его там.

## Архитектура

```
Vox/
├── App/            точка входа, вкладки
├── Audio/          микрофон (AVAudioEngine → 16 кГц PCM), конвейер записи, AAC-кодирование, фоновый keep-alive
├── Device/         Omi BLE (CoreBluetooth), сборка фреймов, декодер Opus (libopus)
├── Transcription/  Deepgram live (WebSocket), пакетная расшифровка (Deepgram / Whisper), сборка сегментов
├── AI/             клиент LLM (OpenAI-совместимые + Anthropic), сводки и шаблоны, чат с контекстом
├── Services/       хранилище (JSON-файлы в Documents), очередь обработки, контроллер записи, импорт
├── Views/          SwiftUI-экраны
└── Models/         модели данных и настройки
```

Протокол Omi взят из открытого исходного кода [BasedHardware/omi](https://github.com/BasedHardware/omi):
сервис `19B10000-…`, аудио `19B10001-…`, кодек `19B10002-…` (1 = PCM 8 кГц, 20/21 = Opus 16 кГц),
пакет = `[индекс lo][индекс hi][номер части][данные]`.
